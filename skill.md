# BlogiFy Lovable Skill

This repository is connected to Lovable and should be treated as a live workspace for the BlogiFy project.

## Working guidelines
- Make small, focused changes.
- Keep the branch in a working state.
- Avoid destructive edits.
- Do not force-push.
- Do not rewrite published git history (no rebase/amend/squash of pushed commits).
- Prefer safe, incremental updates over large refactors.

## Project context
- BlogiFy is a blog / blogging project.
- The codebase is primarily TypeScript.
- Other parts of the repo may include PLpgSQL, CSS, and JavaScript.

## Lovable usage
When editing this repository from Lovable, preserve existing behavior unless a change is explicitly requested. If you need to add or modify functionality, keep the implementation minimal and maintainable.
